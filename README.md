# paradise-nursery-shopping-cart-app
Paradise Nursery is an interactive, React-based e-commerce application designed for online plant shopping. The application allows users to explore a categorized selection of houseplants, view product details, add items to a shopping cart, and seamlessly manage item quantities using Redux Toolkit for state management.

## Project Structure
- **Landing Page:** Introduces Paradise Nursery with a background visual and "Get Started" call-to-action.
- **Product Listing:** Organizes 18+ unique houseplants across 3 distinct categories with dynamic "Add to Cart" state toggles.
- **Shopping Cart:** Features real-time price calculation, item increment/decrement, deletion, and checkout placeholder functionality.

## Technologies Used
- React.js
- Redux Toolkit (`@reduxjs/toolkit` & `react-redux`)
- CSS3 (Responsive Design)
